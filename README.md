
# Portal Manufacturing Orders (Odoo 17)

## Use Case

In manufacturing businesses, customers often need visibility into the progress of their custom or made-to-order products.

By default, Odoo provides Manufacturing Orders through the backend, making them inaccessible to customers using the standard Customer Portal.

This module bridges that gap by allowing portal users who follow a Manufacturing Order to view its details, track production progress, communicate through chatter, and download the Production Order PDF.

## Features

- **Manufacturing Order List:** View followed Manufacturing Orders with pagination.
- **Search:** Search by Manufacturing Order name or product.
- **Filters:** Filter orders by manufacturing status.
- **Sorting:** Sort by date, name, or status.
- **Order Details:** View product, quantities, production status, planned dates, responsible person, and components.
- **Chatter:** Access the Manufacturing Order's communication history.
- **PDF Download:** Download the standard Odoo Production Order report.
- **Access Control:** Restrict portal access to Manufacturing Orders associated with the logged-in user's partner as a follower.
